# LifeLink - Blood Donor Finder

LifeLink is a blood donation management system that helps users find available blood donors and create emergency blood requests.

## Features

- Register blood donors
- Search donors by name or location
- Filter donors by blood group
- Filter donors by availability
- Create emergency blood requests
- View emergency requests
- Update request status
- Delete donor and request records
- Firebase Firestore database
- Express.js backend

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Firebase Firestore
